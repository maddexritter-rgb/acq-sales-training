# Instructions for the installing assistant

1. Clone this repository into a new local directory if it is not already available. Never replace an existing checkout or skill blindly. Read the skill directly now so the current call can proceed without a session restart.
2. To persist the skill, run the repository bootstrap with `--install codex` or `--install claude` and `--project /absolute/path/to/the/users/project`. Choose the current user's project, not the downloaded repository, unless that repository is their chosen working project. This creates `.agents/skills/sales-call-audit` for Codex or `.claude/skills/sales-call-audit` for Claude Code. It preserves existing different installations and reports a conflict instead of overwriting. No global install or security-setting change is necessary. If only use was requested, skip persistent installation and read the skill directly.
3. For a recording, run `bash skills/sales-call-audit/scripts/start.sh INPUT NEW_OUTPUT` on macOS/Linux or `powershell -File skills/sales-call-audit/scripts/start.ps1 INPUT NEW_OUTPUT` on Windows. Quote paths. The launchers obtain a private uv/Python runtime automatically when needed, then install the local audio dependencies. They do not change shell profiles or require a transcription API key. Use a new output under the user's project `results/` directory. Preserve the original recording. For text, use the skill's transcript route without installing audio dependencies.
4. Read all generated turns, warnings, and applicable coaching references. Confirm roles from content when clear; ask only if genuinely ambiguous. Give the most useful finding, a timestamped replay, specific replacement words, and one practice target in the same conversation. Do not stop at “transcription complete.”

Installation command on macOS/Linux: `bash skills/sales-call-audit/scripts/start.sh --install codex --project /path/to/project` (substitute `claude` for Claude Code). On Windows use the PowerShell launcher with the same arguments. A single installation command installs only the skill; the runtime/model download happens when a recording is processed.

Explain the first run briefly: “I’m setting up the local transcription tools, then I’ll review the call.” Let the host enforce its normal permissions. If the user declines execution/network access, accept a transcript instead. Do not promise instant first-run completion, bypass host prompts, or ask the user to obtain API keys. Existing Claude Code/Codex access is required and is separate from free local transcription.
