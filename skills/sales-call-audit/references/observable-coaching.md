# Observable coaching

The unit of feedback is a behavior that can be heard or read, not a trait assigned to a person. Match the uploaded call's objective and stage. A clear negative ending permits a firm critique; it does not prove the counterfactual sale would have closed.

## Construct the finding

1. Locate the buyer statement that establishes the need or constraint.
2. Locate what the rep actually said or omitted at the next relevant decision.
3. Show the buyer's observed response. If it is silence, report silence; do not infer the reason from sequence alone.
4. Choose the smallest useful change, informed by the supplied training method.
5. Write the actual replacement words. State what the rep should wait for and how the next move changes with the buyer's answer.
6. Define a practice check an observer could apply to another call.

Prefer verbs: repeat, ask, pause, name, confirm, compare, explain, invite, schedule. Replace abstract advice with observable acts:

| Vague feedback | Usable feedback |
|---|---|
| Build trust | Restate the buyer's previous failure, then ask what would need to be different this time. |
| Improve discovery | Ask what happens when the owner is absent, then ask for the last example. |
| Establish value | Connect one confirmed problem to one verified feature and explain what changes for the buyer. |
| Be more empathetic | Acknowledge the correction and remove the rejected assumption from the next question. |
| Handle the objection better | Ask which part remains unresolved, answer that part, then check whether the answer addressed it. |
| Be confident | With transcript-only evidence, do not prescribe confidence. Identify the unfinished ask, uncertain claim, or unnecessary wording that is actually visible. |

## Writing discipline

Short, plain sentences. Concrete nouns from the call. One idea per sentence when possible. Direct criticism of the behavior, without insults about intelligence, character, or motivation. No manufactured aggression, catchphrase imitation, motivational monologue, or profanity added just to sound like a trainer.

Remove filler such as “the rep should better align with the prospect's needs” unless followed by a specific action; normally replace it entirely. Do not use generic question chains mechanically: an answered question is a reason to advance, not to repeat it in different words. Do not turn every call into proof that the rep needs more pain discovery.

## Final check before delivery

Can a manager point to the evidence? Could a rep say the replacement aloud? Does the replacement address what the buyer actually said? Is the claim about the offer verified? Does the next branch allow a correction or a real no? Can another reviewer tell whether the practice behavior happened? If not, revise before responding.
