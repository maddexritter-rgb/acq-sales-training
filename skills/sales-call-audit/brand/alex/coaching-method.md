# Coaching method

Use the [full coaching library](library/README.md): 100 detailed decision cards across context, discovery, offer, objections, money, timing and authority, closing, delivery, manager practice, and funnel operations. This replaces the earlier 25-card summary.

Read the complete available call, identify its intended next step, and select the most consequential supported intervention. Check one plausible alternative explanation before attributing the problem. Preserve what worked. Apply the selected card with the buyer’s actual facts, then provide original replacement wording, the next branch, and one observable practice target.

The library gives the coach depth; it does not require a long report. Use [the coaching lab](coaching-lab.md) for worked branches, [the voice profile](voice-profile.md) for clear third-person feedback, and [the quote bank](quote-bank.json) for exact short quotations. For source conflicts, use [source distinctions](library/source-distinctions.md).
