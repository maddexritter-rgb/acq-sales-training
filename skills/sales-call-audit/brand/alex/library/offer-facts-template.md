# Offer facts for accurate scripts

Use available information first. Leave unknowns explicit and ask only the question that changes the recommendation. This is a working note, not required onboarding paperwork.

- Call job: setting / discovery / closing / follow-up / renewal / onboarding.
- Buyer: current situation, desired change, confirmed obstacle, prior attempts.
- Offer: actual deliverables, exclusions, delivery model, implementation work and owner.
- Terms: current total price, approved payment options, dates, eligibility, cancellation and guarantee terms.
- Evidence: approved proof and its limitations; what the rep may truthfully claim.
- Decision: participants, authority, criteria, prerequisites, next useful milestone.
- Open facts: unknown item, person who can verify it, when an answer is needed.
- Outcome: observed action, buyer promise, verified external status, and unknown later events separately.

If the buyer requires ongoing implementation but the only known offer is a workshop, write a scope-verification response. Do not invent ongoing consulting. If an attendance date is uncertain, use a conditional scheduling line, not an invented opening. If terms are missing, coach the diagnosis now and leave the payment wording conditional.
