# Coaching lab: diagnosis, replacement, practice

These are original teaching examples, not actual prospect transcripts, source quotations, or complete handbook scripts. Use the decision cards for principles and provenance. Adapt the intervention to the observed call; never paste a scenario as if it happened. Sources use the IDs in source-profile.md. The exercises and evaluation criteria are our implementation of the training, not claimed quotations.

## Choose the move before writing advice

For the strongest candidate moment, identify: the buyer's stated issue; what the rep did; the buyer's actual next response; what information was still missing; and the smallest better action. Consider an alternative explanation before naming the failure. A price followed by silence could mean price resistance, a dropped connection, or a missing transcript segment. If the evidence does not distinguish them, the advice is to clarify, not to pressure.

Trace a late objection backward. If the buyer mentioned the same constraint during discovery, show the earlier chance to address it. If the earlier context is unavailable, don't invent a missed opportunity. Choose the first supported point where a different action could have improved understanding or the next step—not the earliest imaginable mistake.

Use one of the following patterns only when it fits. Let the real buyer's language replace the example's nouns.

## A. The rep's diagnosis survives the buyer's correction

**Signal:** The buyer explains that a process exists; the rep keeps asking about not having it.
**Weak advice:** “Listen actively and build rapport.”
**Useful feedback:** “The buyer corrected the premise. The next question repeated it. The rep needs to update the recap before continuing.”
**Suggested dialogue:** “Understood—the process exists. The issue is what happens when it isn't followed. Is that accurate?” [wait]
- If yes: “Walk me through the most recent time that happened.” [wait]
- If corrected: restate the corrected version, then ask one question about it.
- If the buyer says there is no problem: stop manufacturing one; clarify why they took the call.
**Practice:** The buyer corrects a different detail each round. The rep passes the attempt when the revised recap reflects that correction and the next question does not reintroduce the rejected premise.
**Basis:** DIS05, DIS06, and DIS09; H1 discovery; V2 10234–10254s.

## B. The buyer gives a category instead of an example

**Signal:** “We need better sales,” “Hiring is a mess,” or “We want to scale.”
**Useful feedback:** “The rep pitched a solution before finding out what the category meant in this business.”
**Suggested dialogue:** “Think about the most recent time this caused a problem. What happened?” [wait] “What happened next?” [wait]
- If a specific bottleneck appears: recap it and ask how it affects the stated goal.
- If the answer remains vague: narrow to an observable step—who does what today, and where does it stop working?
- If the buyer does not know: acknowledge the gap; don't supply invented metrics.
**Practice:** The rep turns a broad complaint into one concrete example without feeding the buyer a problem to agree with.
**Basis:** DIS02 and DIS05; H1 discovery; V1 3507–3609s; V2 10034–10096s.

## C. A past purchase failed

**Signal:** The buyer mentions an existing provider or an earlier disappointing purchase.
**Useful feedback:** “The rep criticized the old provider before learning what failed. That leaves the buyer defending the old decision instead of explaining the unmet need.”
**Suggested dialogue:** “What part helped?” [wait] “What did it leave unresolved?” [wait]
- If the gap matches a verified capability: explain that capability and why it addresses this gap.
- If the gap is implementation and the offer only provides education: state that limitation; don't relabel education as implementation.
- If the buyer cannot identify a gap: clarify the reason for considering a change.
**Practice:** Preserve one thing that worked, name one confirmed gap, and connect only an actual capability to it.
**Basis:** DIS07; V1 3759–3820s; V2 10034–10096s. The respectful wording is an adaptation, not a verbatim source script.

## D. The pitch is a tour of features

**Signal:** The buyer has named a problem, but the rep lists modules, meetings, dashboards, or company credentials without connecting them to that problem.
**Useful feedback:** “The buyer asked how this would change the situation. The rep described what the package contains.”
**Suggested dialogue template:** “The problem is [confirmed buyer problem]. [Verified capability] helps by [actual mechanism]. For the team, that means [supported practical change]. Does that address the part that matters here?” [wait]
Fill every bracket from evidence. If the mechanism is unknown, ask the offer owner for it; do not invent one.
- If yes: confirm any material remaining constraint, then make the appropriate ask.
- If no: ask which part remains unresolved and change the explanation.
- If the buyer asks about delivery details: answer; concision is not permission to hide work or terms.
**Practice:** Rewrite one feature explanation into one buyer-specific explanation. Pass when the buyer's issue is still recognizable and no promise was added.
**Basis:** OFF01 and OFF02; H1 offer; V2 10154–10418s.

## E. “It's too expensive” has several meanings

**Signal:** The buyer objects to cost without specifying the issue.
**Useful feedback:** “The rep offered a discount before finding out whether the concern was affordability, timing, or value.” Only use this finding if a premature discount actually occurred.
**Suggested dialogue:** “What makes the cost difficult in this situation?” [wait]
- If cash is unavailable: acknowledge affordability; check only existing approved alternatives or end cleanly.
- If value is unclear: ask what outcome would make the purchase worthwhile, then assess whether the offer can credibly support it.
- If the concern is another failed purchase: ask what failed before and what evidence would help evaluate this one.
- If the buyer is comparing alternatives: compare actual scope and requirements, not imagined competitor weaknesses.
**Practice:** The manager secretly chooses one concern. The rep must identify it from the buyer's answer before proposing a response. Do not use debt, shame, or imaginary ROI to force a purchase.
**Basis:** MON01; H1 money concerns; V2 6298–6325s. The branching dialogue is an original adaptation.

## F. A stakeholder is missing

**Signal:** Another person needs to approve, share the decision, or implement the purchase.
**Useful feedback:** “The rep tried to get a decision from someone who said the decision was shared.”
**Suggested dialogue:** “What would that person need to evaluate before deciding?” [wait] “Would a conversation together help answer those questions?” [wait]
- If yes: agree purpose and participants before scheduling.
- If no: ask how the actual decision process works and what material would be useful.
- If the buyer is declining: respect the refusal; don't treat every partner reference as a tactic.
**Practice:** The rep distinguishes decision authority from implementation responsibility and proposes a next step suited to the actual process.
**Basis:** TIM06 and TIM08; V2 6390–6418s; H1 stakeholder/next-step guidance. Multi-call business sales are not graded as one-call consumer closes.

## G. “I'll think about it” ends the conversation

**Signal:** The buyer asks for time and the rep either accepts a vague follow-up or launches a memorized rebuttal.
**Useful feedback:** “The rep did not find out what was left to decide.” Use only if no specific unresolved issue was already named.
**Suggested dialogue:** “What would be useful to think through before deciding?” [wait]
- If a specific concern emerges: address it, check the response, and ask what next step makes sense.
- If another participant or document is needed: agree how that information will be obtained.
- If the buyer wants time without discussion: respect that; offer a specific follow-up only if welcome.
**Practice:** Learn one actual decision criterion before giving advice. The buyer is allowed to say no; success is a clarified decision, not forced agreement.
**Basis:** OBJ03 and TIM05; V1 4605–4706s; V2 10609–10717s.

## H. The rep asks, then answers for the buyer

**Signal:** After a clear question or buying request, the rep immediately supplies more arguments instead of leaving room for an answer. Confirm the sequence from reliable turn evidence or audio.
**Useful feedback:** “The rep added another explanation before learning the buyer's answer. Stop after the question.”
**Suggested dialogue:** Ask the stage-appropriate question in one sentence. [wait for the buyer]
- If the buyer asks a question: answer that question, then check whether it resolved the issue.
- If the buyer raises a concern: clarify that concern.
- If the audio may have dropped: check the connection. Silence is not itself an objection.
**Practice:** Ask one question and let the practice partner answer. Assess turn-taking, not an arbitrary universal number of seconds.
**Basis:** CLS02 and DEL01; H1 tone; V2 10764–10880s.

## I. Interest is mistaken for a next step

**Signal:** “Sounds good” is recorded as a booked meeting or a closed sale, although no concrete action was agreed.
**Useful feedback:** “The buyer expressed interest. The call ended without an agreed next action.”
**Suggested dialogue:** “Would [specific appropriate next step] be useful?” [wait]
- If yes: agree who is involved, what it is for, and when it will happen.
- If the buyer needs information first: establish what they need and who will send it; do not claim the meeting is booked.
- If no: clarify only if welcome, then end respectfully.
**Practice:** Finish with an action and owner the buyer actually accepted. Distinguish verbal intention, scheduling, payment submission, and confirmed payment.
**Basis:** CLS06 and CLS08; H1 next-step guidance; V2 10717–10755s.

## J. A successful close contains a coaching issue

**Signal:** The call ends in a purchase, but the rep also ignores a correction, invents a claim, or makes an unclear promise.
**Useful feedback:** “The purchase was a positive outcome. This particular claim still needs correction.” Name the exact behavior rather than discounting the entire call.
**Suggested action:** Keep the successful discovery or ask; replace the unsupported promise with verified scope. If the user requests customer follow-up, draft it, but do not send it automatically.
**Practice:** Compare two calls with similar stages and offers. Identify the behavior in both without assuming the win proves causality or the loss proves incompetence.
**Basis:** MGR05 and OPS02; H1 training; V2 6000–6138s.

## Run practice as a conversation

Offer practice after useful feedback. If the uploader has not chosen to play the rep, say “A rep can practice this response here; a manager can also use the drill with the team.” Do not start impersonating a real buyer unprompted.

When practice is requested: name the single target, present one fictional buyer line, and stop for the learner's response. Do not write both sides and count that as practice. Give immediate feedback on that target: what the learner actually did, one correction if needed, and a retry of the same moment. After a successful attempt, change one buyer detail to test transfer. Correct words alone do not prove vocal delivery; text practice cannot validate tone. End with what to look for in the next real call.

On the next call, compare the selected behavior only at applicable opportunities. Report “used in 2 of 3 observed opportunities,” with call moments, rather than a fabricated overall coach score. No opportunity means not observable, not a failure. Keep the practice record local and omit prospect identifiers from reusable training material.
